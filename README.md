# WerbeTracker public product website

Static independent landing page for public product information and Riot product proposal. The separate WerbeTracker app source and actual player archives must remain private.

## Setup

Create a **public** GitHub repository named exactly `WerbeName.github.io` under GitHub account `WerbeName`, and upload `index.html`, `privacy.html`, `terms.html`, `styles.css`, and `.nojekyll` to its root. In **Settings → Pages**, choose **Deploy from a branch → main → /(root)** and save. Once deployed, open `https://werbename.github.io/`.

The public website is informational and no public application link or player data is included. Before applying for a production Riot API key, replace the general contact route with a dedicated email/contact mechanism, review privacy/legal terms, provide working prototype access/screenshots/flows for the Riot reviewer, and add any required `riot.txt` token at this root ONLY after obtaining it from Riot. The verification token must match exactly and should be removed after verification as Riot directs.

Site has no JavaScript, trackers, external fonts, third-party images, secrets, or private repo link. All charts are illustrative.
